What it does

  • EXAAPIKEY: Your Exa API key.
  • OPENAIAPIKEY: Optional For OpenAI function calling example.
  • ANTHROPICAPIKEY: Optional For Anthropic tool use example.
  • quickstart.py: A simple script to demonstrate a basic search using exa-py.
  • openaifunctioncalling.py: Demonstrates how to use Exa as a tool with OpenAI's GPT models.
  • anthropicfunctioncalling.py: Demonstrates how to use Exa as a tool with Anthropic's Claude models.
